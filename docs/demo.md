# Demo script (3 minutes)

| Time | Beat | Say / do | Real? |
|---|---|---|---|
| 0:00 | Problem | "Small businesses burn ad money and can't tell what's working." | |
| 0:20 | Research | Ask: "I sell [X], who should I learn from?" Agent pulls 5 competitor IG ads via Monid and names the patterns. | Real |
| 0:50 | Create | Agent writes 3 variants with different hooks into the creative library. | Real |
| 1:20 | Launch | Agent picks manual vs Advantage+ out loud ("new account, no pixel data, going manual"). Show the live campaign in Ads Manager. | Real |
| 2:00 | Direct spend | Trigger the monitor. Agent reads live spend/CTR/CPC, flags the weakest ad, proposes a pause. Say "approve". Refresh Ads Manager: ad is paused. | Real money, real write |
| 2:40 | Close | "It researches, creates, launches, and keeps optimizing. You just approve." | |

## Lines to have ready

- **"Where's ROAS?"** "Ten dollars of traffic won't produce purchases. CTR and CPC are the leading signals; ROAS follows once the pixel sees conversions. The agent already handles it when the data exists."
- **"Is it real-time?"** "Meta refreshes insights about every 15 minutes. The agent checks on that cadence."

## Backups

- Screen recording of the full flow the first time it works end to end.
- Cached Monid results for the demo competitor.
- A pre-made campaign in Ads Manager in case a live create call fails.
- Screenshot of the agent's best recommendation, in case Meta's API is slow on stage.
